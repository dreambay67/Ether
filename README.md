# Ether

Ether 4.0 is a Windows-first, local-first desktop node canvas for DreamBay creative workflows. Each creative document is one portable `.ether` file.

Ether 2.x folder projects are unsupported. Ether 4.0 does not import or migrate the legacy `project.json`, `graph.json`, and `ether.db` project layout.
